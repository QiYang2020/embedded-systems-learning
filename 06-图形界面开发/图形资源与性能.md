# 图形资源与性能

## 资源链

```text
设计稿
→ 字体、图片和图标
→ 转换、压缩或打包
→ 固件或文件系统
→ 运行时加载与解码
→ 渲染
```

## MCU重点

- Flash和RAM容量
- 字库字符范围
- 图片格式和解码开销
- 刷新区域和色深
- CPU渲染、DMA2D等二维加速

## Linux/RK重点

- 文件系统和资源更新
- 字体渲染与图片解码
- GPU纹理和合成
- 启动时间和内存占用

GUI性能由CPU、RAM、内存带宽、显示接口、分辨率、刷新区域、资源解码、加速能力和任务调度共同决定。
