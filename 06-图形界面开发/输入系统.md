# 输入系统

## 输入链路

```text
触摸芯片、按键或旋钮
→ I²C/SPI/GPIO驱动
→ 坐标、按键或增量数据
→ GUI输入适配层
→ 控件事件
```

输入驱动和显示驱动是独立支线。二者在GUI框架汇合，而不是互为父子。

## MCU关注点

- 触摸控制器初始化和坐标读取
- 中断或轮询
- 坐标旋转、缩放和校准
- 消抖、长按和旋钮增量
- GUI线程安全

## Linux关注点

- Linux Input子系统
- evdev事件
- 设备树与触摸驱动
- GUI框架的输入后端
