# MCU片上外设与外部器件

## 为什么需要区分

“外设”在MCU开发中可能指芯片内部的外设控制器，也可能指板外连接的具体器件。两者处在不同层级，开发方法也不同。

## MCU片上外设

片上外设集成在MCU内部，例如：

- GPIO
- UART、I²C、SPI控制器
- 定时器、PWM
- ADC、DAC
- DMA
- CAN、USB控制器

开发重点是理解控制器机制、引脚复用、寄存器、时钟、中断和DMA。通常先使用厂商HAL或LL，不必为每个项目从零重写控制器驱动。

## 外部器件

外部器件通过板级接口连接，例如：

- I²C传感器
- SPI Flash
- 电子纸控制器
- NFC芯片
- IMU
- 电机驱动器

开发重点是阅读器件数据手册，实现命令、寄存器、初始化、数据转换、状态检测和异常恢复。

## 调用关系

```text
业务功能
→ 外部器件驱动
→ MCU片上外设API
→ 片上控制器
→ 物理线路
→ 外部器件
```

## 示例

“驱动一块SPI电子纸”通常不是重新实现STM32的SPI控制器，而是：

1. 使用HAL或LL配置SPI。
2. 控制CS、DC、RST和BUSY等GPIO。
3. 按电子纸芯片手册发送命令和图像数据。
4. 处理刷新等待、超时、休眠和异常。
5. 向上层提供初始化、显示、清屏等API。

## 目标深度

- 片上外设：理解、配置、调试，必要时追踪到寄存器。
- 外部器件驱动：能够依据数据手册独立实现和维护。
