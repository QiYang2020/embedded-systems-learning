# Embedded Systems Learning

面向嵌入式系统学习、工程实践与技术应用分析的 Obsidian 知识库。

## 纵向技术主干

- 电子与硬件基础
- STM32：MCU、外设与实时控制
- Rockchip RK：嵌入式 Linux、Android、驱动与上层应用
- 外设与通信：NFC、显示、传感器、USB、无线与现场总线
- 嵌入式工程：工具链、调试、选型、可靠性与协作

正点原子和野火作为开发板、课程及参考实现来源，不与具体技术领域平级。

## 横向应用案例

应用案例用于检验多个纵向能力能否被组合起来。NFC 水墨屏是其中一种跨层应用，也是观察技术深度的指标之一，但不是整个知识库的学习主线。
