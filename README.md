# Embedded Systems Learning

面向嵌入式软件、MCU固件、外设驱动、RTOS、嵌入式GUI和RK/Linux平台适配的Obsidian学习仓库。

## 当前定位

- 主要参与：MCU固件、外部器件驱动、常用接口、RTOS、GUI和平台集成。
- 按需参与：BSP、设备树、简单Linux驱动和系统构建。
- 获知边界：硬件兼容性、信号干扰、原理图、PCB和复杂厂商底层栈。

详细定义见[开发参与层与边界](00-导航/开发参与层与边界.md)。

## 使用方式

克隆仓库后，将仓库根目录作为Obsidian Vault打开。GitHub README使用标准Markdown链接；知识库内部使用Obsidian双链。

## 内容成熟度

当前大部分内容属于知识骨架，并不等同于已经实验验证。成熟度规则见[元数据与成熟度规范](00-导航/元数据与成熟度规范.md)。后续将按“权威来源 → 最小实验 → 验证记录”逐步深化。
