# 裸机、状态机与RTOS

## 裸机主循环

最简单结构：

```c
while (1) {
    read_input();
    update_logic();
    drive_output();
}
```

问题通常来自阻塞延时：某个功能等待时，其他功能也无法运行。

## 非阻塞状态机

```text
空闲 → 启动 → 等待硬件 → 完成 → 空闲
                ↘ 超时/错误
```

状态机是进入RTOS前必须掌握的能力，也适用于协议、设备驱动和业务流程。

## RTOS

RTOS提供任务调度、队列、信号量、事件和软件定时器，适合多个并发职责。但它不会自动解决逻辑混乱。

## 何时使用

- 简单单功能设备：裸机循环或状态机
- 多个并发通信和控制职责：考虑RTOS
- 需要Linux生态、文件系统和复杂网络：考虑MPU/SoC

## 常见风险

- 任务栈不足
- 优先级设置错误
- 互斥锁死锁
- 优先级反转
- 中断与任务共享数据竞争

## 学习顺序

阻塞式例程 → 非阻塞定时 → 状态机 → 事件队列 → RTOS任务。
