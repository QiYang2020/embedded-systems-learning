# 寄存器与内存映射

## 核心概念

MCU将Flash、RAM和外设寄存器映射到统一地址空间。CPU读写特定地址，就可以读取GPIO状态、配置SPI或启动定时器。

```text
CPU执行读写指令
→ 地址总线定位寄存器
→ 外设控制逻辑响应
→ 硬件状态改变
```

例如“点亮LED”最终通常是修改GPIO输出数据寄存器中的某一位。

## 为什么使用volatile

硬件寄存器可能被外设或中断改变。volatile告诉编译器，每次都应真实读取或写入，不能假定值不变并将访问优化掉。

## HAL与寄存器

```text
业务代码
→ HAL函数
→ CMSIS设备定义
→ 寄存器地址
→ 硬件
```

不必一开始背寄存器。先用HAL完成实验，再沿调用链找到关键寄存器，对照参考手册理解位域含义。

## 常见误解

- 寄存器不是普通RAM变量。
- 修改保留位可能产生不可预期行为。
- 数据手册侧重器件指标；参考手册解释外设寄存器和功能。
