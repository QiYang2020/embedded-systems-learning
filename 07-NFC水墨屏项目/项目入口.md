# NFC 水墨屏项目

## 项目目标

以 NFC 水墨屏为第一条完整实践主线，串联 NFC 通信、能量采集、低功耗设计、电子纸驱动、图像处理、STM32 与 RK 上位系统。

## 待确认的产品形态

- 手机贴近后更新内容，还是 RK 主机统一管理
- 有源供电、无源 NFC 取电，或混合供电
- 屏幕尺寸、颜色数量、分辨率和刷新时间
- 单标签还是多标签批量更新
- 是否需要 STM32，或由带 MCU 的 NFC 芯片直接驱动
- 内容来源、编码格式与安全要求

## 子链路

1. 手机或 RK 生成显示内容
2. 图像转换为电子纸数据
3. NFC 建链并传输
4. 设备接收、校验与存储
5. 电子纸刷新
6. 设备休眠或断电保持

## 第一项实验

先完成“有源供电 + STM32 + SPI 电子纸”的稳定显示，再引入 NFC 数据传输与无源供能，避免同时调试通信、供电和显示三个变量。
