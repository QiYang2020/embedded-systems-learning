# IDE与工程结构

## IDE不是单一工具

```text
编辑器
+ 工程配置
+ 构建系统
+ 编译器与链接器
+ 调试前端
+ GDB Server
+ 烧录工具
```

学习IDE时应能回答：

- 实际执行了什么编译命令
- 宏、头文件和库路径来自哪里
- 链接脚本在哪里
- 输出了哪些ELF、BIN、HEX和MAP文件
- 调试器通过什么服务器连接目标板
- 哪些配置是厂商专有、哪些可替换

## AI协作要求

提供工程目录、版本、完整构建日志和可复现命令。只有GUI截图通常不足以定位问题。

## 目标深度

可以先借助CubeIDE等厂商工具快速跑通，但应逐步做到离开图形向导后仍能解释构建、烧录和调试过程。
