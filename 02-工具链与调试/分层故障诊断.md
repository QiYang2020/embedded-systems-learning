# 分层故障诊断

本页的方法对应[[00-导航/反向排障链路]]：实现链通常从底层能力向产品功能汇入，诊断则从可见现象向上游依赖逐层回溯。

## 诊断顺序

1. 明确预期结果和实际现象。
2. 固定硬件、软件和版本基线。
3. 判断问题所属层级。
4. 获取日志、波形、返回值或寄存器证据。
5. 构造最小复现。
6. 每次只改变一个变量。
7. 记录结论和恢复方法。

## 常见层级

```text
业务逻辑
→ 用户态程序
→ 系统服务和权限
→ 驱动与设备树
→ MCU固件和协议
→ 板级接口
→ 电气连接和硬件
```

## AI协作

向AI提供事实而不是结论：准确型号、版本、接线、完整日志、最小代码、复现步骤和已验证条件。AI提出的假设必须通过实验验证。
