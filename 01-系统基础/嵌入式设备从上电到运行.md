# 嵌入式设备从上电到运行

## STM32的典型流程

```text
供电稳定
→ 复位
→ CPU读取向量表
→ 执行Reset_Handler
→ 初始化data和bss
→ 配置系统时钟
→ 进入main
→ 初始化外设
→ 主循环或RTOS调度
```

向量表保存初始栈指针和异常/中断入口。启动代码在进入main之前准备C语言运行环境。

## RK/Linux的典型流程

```text
上电
→ 芯片BootROM
→ 加载引导程序
→ U-Boot初始化硬件
→ 加载Kernel与设备树
→ 挂载RootFS
→ 启动init/systemd
→ 系统服务与应用
```

## 排障分层

1. 电源和复位是否正常
2. 时钟是否建立
3. 是否进入启动代码
4. 固件或引导程序是否被正确加载
5. 内核或main是否开始执行
6. 外设初始化是否阻塞
7. 应用逻辑是否异常

## 最小实验

STM32在main第一行翻转一个GPIO并输出串口日志；RK查看串口启动日志，标出BootROM、U-Boot、Kernel和用户空间的边界。
