# Flash、RAM、栈与堆

## 基本关系

- Flash断电后仍保留，通常存放代码和只读数据。
- RAM断电后丢失，用于运行时变量、缓存和任务栈。
- 栈保存局部变量、返回地址和调用现场。
- 堆用于动态分配，生命周期由程序管理。

## 常见数据区域

| 区域 | 内容 |
|---|---|
| text | 程序机器码 |
| rodata | 只读常量 |
| data | 有初值的全局/静态变量 |
| bss | 零初始化的全局/静态变量 |
| stack | 函数调用和局部数据 |
| heap | malloc/new等动态分配 |

data段的初值保存在Flash中，启动时复制到RAM；bss段在启动时清零。

## 嵌入式风险

- 大型局部数组可能导致栈溢出。
- 动态分配可能产生碎片和不可预测失败。
- RTOS中每个任务通常有独立任务栈。
- 显示帧缓存、网络缓存和图像数据很容易耗尽RAM。

## 与Unity的联系

Unity中大量内存问题由运行时和GC管理；MCU通常没有完整托管运行时，内存上限和生命周期必须显式考虑。
