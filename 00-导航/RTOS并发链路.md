# RTOS并发链路

## 主链

并发职责与实时约束 → 中断/DMA事件 → 任务划分 → 队列/通知/事件组 → 互斥与优先级 → 内存和栈 → 可运行的RTOS系统

## 定位

RTOS不是MCU学习的固定下一阶段。只有当系统存在多个并发职责、阻塞等待、实时响应或资源共享时，它才成为合适的组织方式。

- 可替代：FreeRTOS与RT-Thread可处于相似层级，但生态和设备框架不同。

## 常见断点

中断里做过多工作、任务职责不清、阻塞调用未识别、锁粒度错误、优先级反转、栈不足和动态内存碎片。
