# MCU固件链路

## 主链

体系架构与芯片平台 → 启动文件/链接脚本/时钟/内存 → 中断与运行时 → 片上外设 → 轮询/中断/DMA → HAL/LL/寄存器接口 → 固件模块 → 产品功能

## 分支与汇入

- GPIO、定时器、ADC与各通信控制器是并行的片上外设分支。
- 轮询、中断和DMA是数据与事件处理方式，按实时性和吞吐量选择。
- HAL、LL、厂商SDK和寄存器开发是同一位置的不同抽象层，不是四个连续阶段。
- 状态机、RTOS、协议栈和GUI在固件系统层汇入，但都不是所有项目的必选前提。
