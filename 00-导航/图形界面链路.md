# 图形界面链路

## 主链

产品交互 → 页面与状态 → GUI框架 → 控件/布局/资源 → 渲染 → 显示缓冲与刷新 → 显示控制器/总线 → 面板

输入形成并行支线：触摸/按键/旋钮 → 输入驱动 → 事件系统 → 页面逻辑。

## 平台分支

- MCU：显示器件驱动 → LVGL/TouchGFX → 页面逻辑；RTOS和DMA2D是可选协作或加速能力。
- Linux/RK：内核显示与输入 → DRM/KMS或Framebuffer → 合成/窗口系统 → Qt/LVGL/Android UI → 应用。

## 关系

- GUI框架只是图形开发的中间层，不包含全部显示与输入链路。
- RTOS是运行环境，不是GUI父级。
- GPU、DMA2D和硬件合成是性能分支，不是GUI成立的前提。
- 字体、图片、主题和本地化属于资源支线，最终汇入渲染与内存预算。
