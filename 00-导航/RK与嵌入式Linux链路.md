# RK与嵌入式Linux链路

## 启动与系统链

RK SoC/板级硬件 → BootROM → U-Boot → Linux Kernel → 设备树与BSP → RootFS/系统服务 → 用户态应用

## 设备接入链

外部器件 → 总线控制器 → 内核子系统与器件驱动 → 设备节点/sysfs/input等接口 → 用户态库或服务 → 业务与GUI

## 参与边界

- 主要参与：SDK构建、镜像、系统配置、用户态设备访问、服务和应用部署。
- 按需参与：设备树、U-Boot/Kernel局部修改、简单器件驱动适配。
- 集成为主：复杂SoC控制器、GPU/NPU/ISP、多媒体和厂商闭源栈。
