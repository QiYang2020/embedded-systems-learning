## 各主题的位置

| 主题 | 主要作用 | 当前定位 |
|---|---|---|
| STM32 | 外设控制、协议、实时任务 | 设备控制层 |
| RK 系列 | Linux/Android、联网、界面、边缘计算 | 上层主控 |
| 正点原子 | 开发板、课程、例程 | 学习资料来源 |
| 野火 | 开发板、课程、例程 | 补充资料来源 |
| NFC | 近场通信、数据交换、无源供电 | 通信与供能 |
| 电子纸 | 超低功耗显示 | 输出设备 |
| NFC 水墨屏 | 综合应用 | 第一条项目主线 |

## 基础依赖

- C 语言、内存与指针
- 数字电路、电平与供电
- GPIO、中断、定时器
- UART、I²C、SPI
- 调试器、串口工具、逻辑分析仪
- Git 与实验记录
