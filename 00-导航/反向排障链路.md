# 反向排障链路

## 反向链

功能现象 → 业务状态与日志 → RTOS/并发 → 器件驱动 → 控制器与接口配置 → 数字协议与时序 → 连接、电源和硬件边界

## 使用原则

1. 先固定版本、接线和复现条件。
2. 从最接近现象且最容易观察的下游节点开始。
3. 每层用证据排除或确认，再向上游移动。
4. 每次只改变一个变量，并保留恢复方式。
5. 软件和数字协议证据无法解释时，再转交硬件层分析。

## 证据对应

| 层 | 主要证据 |
|---|---|
| 业务/GUI | 状态、输入事件、页面日志 |
| RTOS | 任务状态、队列、锁、栈水位、时序 |
| 驱动 | 返回值、寄存器值、状态机与错误码 |
| 接口 | 控制器配置、事务日志、逻辑分析仪数据 |
| 系统/BSP | 启动日志、设备树、内核日志、设备节点 |
| 硬件边界 | 连接、供电、电平及需转交的波形问题 |
