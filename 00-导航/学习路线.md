# 学习路线

学习路线由纵向主干构成，横向应用案例用于阶段性验证，不以某一种产品作为唯一终点。

## 主干一：基础与硬件认知

- C 语言、位运算、指针与内存
- 电压、电流、功率和数字电平
- GPIO、时钟、复位、中断
- UART、I²C、SPI
- 编译、烧录、日志和硬件调试

阶段目标：能够看懂基础原理图、数据手册和外设时序。

## 主干二：STM32 与实时控制

- Cortex-M 与内存映射
- HAL、LL、寄存器
- 定时器、PWM、ADC、DMA
- CAN、USB 等常见接口
- FreeRTOS
- Bootloader、低功耗和异常恢复

阶段目标：能够独立完成一个稳定的 MCU 外设控制系统。

## 主干三：RK 与嵌入式 Linux

- Cortex-A 与 SoC 架构
- U-Boot、Kernel、设备树、RootFS
- 交叉编译和镜像烧录
- 内核驱动与用户态接口
- Linux / Android 应用
- 显示、摄像头、音视频、网络与 NPU
- RK 与 MCU 协同

阶段目标：能够理解并修改板级系统，连接驱动与上层业务。

## 主干四：外设与通信

按需求横向扩展：

- NFC / RFID
- 蓝牙、Wi-Fi
- 传感器
- 显示屏
- 电机与执行器
- USB 与现场总线

阶段目标：面对新器件时，能依靠数据手册独立完成选型、接入和验证。

## 主干五：嵌入式工程能力

- Git 与版本管理
- 数据手册和原理图阅读
- 万用表、示波器、逻辑分析仪
- 故障定位与实验记录
- 功耗、稳定性、可靠性
- PCB、BOM 与量产基础

阶段目标：从“例程能运行”提升到“系统可复现、可维护、可交付”。

## 横向应用验证

在各阶段选择小型应用检验掌握程度。NFC 水墨屏是可选案例之一，并非固定主线。

## 课程使用原则

正点原子与野火选择一套作为阶段性主教程，另一套用于交叉验证。课程负责降低入门门槛，技术结论仍应回到芯片手册、官方文档、标准和实验结果。
