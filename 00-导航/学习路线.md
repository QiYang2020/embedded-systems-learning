# 学习路线

## 第一阶段：嵌入式基础

- C 语言与位运算
- 电平、GPIO、中断和定时器
- UART、I²C、SPI
- 编译、烧录、串口日志和硬件调试

完成标志：能够独立跑通一个传感器或显示模块。

## 第二阶段：STM32

- 工程结构与启动过程
- HAL / LL / 寄存器的关系
- DMA、中断与定时器
- FreeRTOS 基础
- SPI 屏幕驱动

完成标志：STM32 可以稳定驱动电子纸并显示自定义图像。

## 第三阶段：NFC 与电子纸

- NFC-A、ISO 14443、NDEF
- NFC 标签与动态 NFC 芯片
- 手机读写
- 电子纸全刷、局刷与休眠
- 图像二值化、抖动和数据打包

完成标志：形成可复现的 NFC 水墨屏最小样机。

## 第四阶段：Rockchip RK

- Linux 基础与交叉编译
- 设备树、内核驱动和用户态接口
- Android / Linux 应用
- RK 与 STM32 的串口、USB 或网络协同

完成标志：RK 作为上位主控管理设备、素材与联网业务。

## 课程使用原则

正点原子与野火选择一套作为主教程；另一套用于交叉验证、补充解释和查找不同实现，不并行逐课重复学习。
