# 元数据与成熟度规范

## 最小Frontmatter

正式技术笔记采用：

```yaml
---
type: concept
maturity: outline
scope: mcu
---
```

## maturity

- outline：只有知识骨架，尚未系统核对。
- researched：已经查阅权威资料。
- verified：已经由实验或工程结果验证。

## 规则

- 不在真实笔记中保留空字段。
- MOC只需要type，不使用含义模糊的active状态。
- 实验、案例和诊断可以使用自己的流程状态。
- 每篇技术笔记应包含权威来源和关联主题。
- 旧笔记逐篇研究时再补元数据，不批量伪装成已验证内容。
