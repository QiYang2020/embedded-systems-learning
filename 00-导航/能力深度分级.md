# 能力深度分级

## 通用等级

| 等级 | 判断标准 |
|---|---|
| L0 识别 | 知道名称、用途和所在层 |
| L1 使用 | 能按可靠例程完成运行 |
| L2 理解 | 能解释原理、参数和数据路径 |
| L3 独立实现 | 能依据文档完成接入或修改 |
| L4 系统整合 | 能组合多层能力并处理异常 |
| L5 工程化 | 能优化可靠性、升级、成本和交付 |
| L6 深入研究 | 能修改核心机制或设计新方案 |

## 评估原则

“达到某级”必须由可复现的实验、代码、日志或案例证明，不能仅以阅读过课程作为依据。标记为“获知”的内容只需知道其可能性、影响和转交边界。
