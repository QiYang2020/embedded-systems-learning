# 实践验证索引

## 定位

实验用于验证链路节点及其连接，不构成固定学习顺序。可依据当前项目，从任意一项进入；缺少前提时再沿对应分链回溯。

| 验证项 | 验证的链路连接 | 可观察结果 | 对应分链 |
|---|---|---|---|
| GPIO输出 | 工程运行时 → GPIO控制器 → 引脚 | LED或电平按预期变化 | [[00-导航/MCU固件链路]] |
| GPIO输入与中断 | 外部事件 → 中断 → 固件逻辑 | 事件可记录且无明显误触发 | [[00-导航/MCU固件链路]] |
| UART日志 | 固件状态 → UART → 主机观察 | 启动、状态和错误信息可读 | [[00-导航/反向排障链路]] |
| 定时器与DMA | 片上事件 → 数据搬运 → 业务处理 | 非阻塞、持续运行且数据完整 | [[00-导航/MCU固件链路]] |
| I²C器件 | 控制器 → 总线 → 器件寄存器 → 驱动API | 可读取ID、状态或传感数据 | [[00-导航/外部器件驱动链路]] |
| SPI器件 | 控制器 → 总线 → 器件命令 → 驱动API | 可读取Flash ID或驱动显示 | [[00-导航/外部器件驱动链路]] |
| RTOS协作 | 中断/事件 → 队列 → 任务 → 业务 | 任务通信稳定且栈可监控 | [[00-导航/RTOS并发链路]] |
| MCU GUI | 显示/输入驱动 → GUI框架 → 页面逻辑 | 控件可显示并响应输入 | [[00-导航/图形界面链路]] |
| Linux设备接入 | 设备树/驱动 → 设备接口 → 用户态 | 用户程序能稳定访问设备 | [[00-导航/RK与嵌入式Linux链路]] |
| 跨平台移植 | 抽象接口 → 平台适配层 → 新SDK | 业务代码少改或不改即可运行 | [[00-导航/跨平台迁移链路]] |
| 综合应用 | 多条分链 → 产品功能 | 功能、日志、异常恢复形成闭环 | [[09-应用案例/应用案例入口]] |

## 记录要求

每次验证保存环境、版本、源码、构建方式、预期结果、实际结果和故障证据。具体芯片型号确定后再补接线与工程模板。
